### Selected work

**[Event Feed Engine](https://github.com/Dhushyanthc/event-feed-engine) — scalable, event-driven backend**

A social-feed backend built in Go that precomputes user timelines when events are created, keeping feed retrieval fast as follower counts grow.

- Implemented fan-out-on-write using Go, PostgreSQL, and Redis.
- Used PostgreSQL as a durable event queue with a transactional outbox, worker pools, and a dead-letter queue.
- Optimized timeline retrieval using Redis sorted sets.
- Deployed on AWS EC2 behind Nginx with Docker and GitHub Actions CI/CD.

`Go` · `PostgreSQL` · `Redis` · `Docker` · `AWS` · `Nginx`

**[Codebase Intelligence Engine](https://github.com/Dhushyanthc/codebase-intelligence) — natural-language codebase search**

A developer tool that answers questions about GitHub repositories with file-level and line-level citations.

- Combined dense vector search and BM25 keyword retrieval using Reciprocal Rank Fusion.
- Implemented syntax-aware code chunking at function and class boundaries.
- Built a query router that bypasses LLM calls for approximately 70% of requests, reducing routing latency from 2.4 seconds to under 10 milliseconds.

`Python` · `FastAPI` · `LangGraph` · `ChromaDB` · `React` · `TypeScript`

**[Khaleezi](https://khaleezi.com) — full-stack e-commerce platform**

A live e-commerce platform built and deployed for a paying client, supporting a catalog of over 100 SKUs.

- Built the React frontend and Node.js REST API with OTP authentication and Razorpay payment integration.
- Designed product data models and an admin dashboard for order fulfillment.
- Integrated an LLM-powered product description generator with SKU-aware prompting.
- Continue maintaining the deployed application and improving its functionality.

`React` · `Node.js` · `Express.js` · `MongoDB` · `Razorpay` · `REST APIs`

**[AI Code Review Agent](https://github.com/Dhushyanthc/ai-code-reviewer) — automated pull request reviews**

A backend service that processes GitHub pull-request webhooks and posts severity-classified review comments.

- Built webhook endpoints using FastAPI and GitHub Webhooks.
- Implemented HMAC-SHA256 signature verification to protect against spoofed requests.
- Automated code review generation using the Gemini API.

`Python` · `FastAPI` · `GitHub Webhooks` · `Gemini API`

**[AI-Powered Astronaut Health Monitoring](https://github.com/Dhushyanthc/astronaut_space_health) — IEEE-published research**

An AI-enabled health monitoring system for analyzing physiological data, detecting anomalies, and supporting predictive health-risk analysis.
